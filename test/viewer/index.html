📖 Viewer EPUB manga

Choisissez un fichier .epub pour l'afficher
Généré par manga-epub. Les EPUB fixed-layout s'affichent page par page (sens manga de droite à gauche via les flèches).

Que tester ?

  • Rendu page par page : les pages doivent remplir l'écran, sans marges ni zoom.
  • Double pages / pages paysage : passe la vue en "auto" — les planches paysage doivent tenir pleine largeur.
  • Couverture : la 1ère page affichée doit être la première page du chapitre (aucune page de couverture séparée).
  • Navigation : la liste "Aller à" liste les chapitres (EPUB fusionné).
  • Métadonnées : en haut à droite, titre + auteur réel (ex: "Eiichiro Oda").
  • Clavier : ← / → pour tourner les pages.
